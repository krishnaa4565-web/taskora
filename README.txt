TASKORA V2
==========
Added:
- Quick Add with simple natural-language date/time parsing
- Calendar month view with task dates
- Card Management with local-only card names, due dates, amounts, fees, notes and manually entered benefits
- Upcoming card-payment summary
- JSON backup now includes cards
- New service-worker cache version

Privacy:
- No card number, CVV, PIN, OTP or bank login is collected.
- Tasks and cards are stored locally in the browser/device.
- The same GitHub Pages link gives separate local data to separate browsers/devices.
- There is no cloud sync in this version.

GitHub Pages:
Upload the files/folders to a repository and enable GitHub Pages.
Open the Pages URL on the phone and use Add to Home Screen / Install.
